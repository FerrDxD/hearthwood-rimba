# Implementasi Lengkap UI Kit v0.5.3 ke Godot 4.x

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mengimplementasikan seluruh desain antarmuka Hearthwood UI Kit (Main Menu v0.5.2, Pause Menu, Buku Catatan 4 tab, Layar Memasak, Toko, Dialog & Gift, serta HUD) ke dalam kode GDScript/Godot 4.x dengan mempertahankan 100% kelulusan test suite dan ergonomi sentuh Android.

**Architecture:** Pendekatan A (Arsitektur Prosedural Terstruktur). Membangun helper tema terpusat (`UIThemeHelper.gd`) untuk token warna `DESIGN.md`, tombol 3D beveled, panel kayu kedai dengan sudut kuningan, dan ceruk slot 48×48. Setiap skrip UI merender komponen taktil berbasis `StyleBoxFlat` dan custom drawing kanvas conifer, tanpa merusak kontrak node atau sinyal yang diuji oleh 21 test suites.

**Tech Stack:** Godot Engine 4.7.2 (GL Compatibility), GDScript, FigCraft UI Kit v0.5.2.

**Spec:**
- `design/Hearthwood_UI_Kit_v0.5.2.figcraft`
- `design/MainMenu_v0.5.2.png`
- `DESIGN.md`
- `PRODUCT.md`
- `PRD Hearthwood Warung Rimba (Versi 0.4.0).md`

## Global Constraints

- **Palet Warna:** Wajib mengikuti `DESIGN.md` (Krem `#F5F5DC`, Coklat Kayu `#8B4513`, Emas `#CD853F`, Sage `#8FBC8F`, Gelap `#333333`, Kayu Gelap `#2E1E14`, Terakota `#E07050`, Rimba `#1E3A1A`).
- **Target Sentuh Android:** Semua tombol interaktif wajib memiliki `custom_minimum_size >= Vector2(44, 44)` (direkomendasikan tinggi 48 px untuk tombol utama).
- **Zero Broken Tests:** Seluruh 21 skrip pengujian di folder `tests/` wajib tetap lolos (ExitCode 0).
- **Bebas Emoji Struktural:** Tidak ada emoji yang digunakan sebagai ikon tombol atau navigasi sistem; gunakan aksen tipografi dan geometri bersih.
- **Resolusi Acuan:** 960 × 540 px (Landscape 16:9).

## Review Focus

1. `MainMenuTest.gd` mengharuskan adanya node `playerName`, `continueButton`, `newGameButton`, `loadButton`, `settingsButton`, `exitButton`, dan `contentPanel`.
2. `UITouchTargetTest.gd` memeriksa 27+ tombol di 8 scene UI agar semuanya memenuhi batas minimum 44×44 px.
3. Dialog dan Gift drawer tidak boleh saling tumpang tindih (*zero layout collision*).
4. Mini-game memasak harus tetap responsif dengan 3 zona timing tungku yang akurat.
5. Slot inventori harus tetap berkapasitas 20 item dan mendukung penandaan tanggal/kualitas masakan.
